What these results answer

One common fixed treatment—not each server’s saturation point.

Every implementation received the same treatment: one isolated io_uring server core, four isolated client cores, and exactly 16 active connections split equally between ngtcp2 and picoquic reference clients. These results compare server performance at that fixed load. They do not claim that C=16 saturates every server or estimate a client-invariant capacity frontier.
